What you're looking at, honestly: the model below is the exact model trained and evaluated in this project (see RESULTS.md for real numbers on real held-out data — average precision ~0.996 across independently randomised scenario replicas). Every score you see on this page is computed live, right now, in your browser, using a hand-written JavaScript forward pass verified to match the trained PyTorch model to within 1e-7 (web/parity.test.mjs). The 60 example windows below are synthetic — generated from summary statistics, never real captured log data (the source dataset's licence forbids redistributing derived data) — so treat their scores as an illustration of the mechanism, not a validation of accuracy. That validation lives in the repository's test suite, against real data.

What this is, and isn't

TESSERA audits and rebuilds a published cloud-anomaly-detection framework (Nagarjun & Rajkumar, IEEE Access 2024), finds that several of its core equations aren't implementable as specified and that its headline 99.4% accuracy comes from a leakage-prone evaluation, and replaces it with a genuinely multimodal detector evaluated honestly — chronological and cross-replica splits, a full leakage certificate, and negative results reported alongside positive ones. Four small encoders (log templates, network metrics, identity, graph structure) feed a Gated Multimodal Unit that handles a missing telemetry source by design. Full write-up, source, and every reported number's derivation: see the repository.
