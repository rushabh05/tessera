Which telemetry sources it used

Switch a source off and the model re-scores live with the rest, using the same masking it uses when a real source goes offline.

Measured caveat: these weights were found to understate a source's true importance in a real test (log templates got 14% of the weight, yet removing them cut average precision from 0.9995 to 0.9846). Read them as a hint about what the model leaned on, not as proof. The ablation study in Real Results is the reliable measure.
